# Personal fork of Herdr (the desktop app)

Fork `schugazi/herdr-app` of upstream `herdrdev/herdr-app`; read upstream's `AGENTS.md` for the code. Edited in `~/herdr-app` on mycroftxxx (branch `master`), built and installed on multivac from `C:\Users\nmsch\herdr-app` with `scripts/fork-install.ps1` (CI's toolchain: Rust 1.95.0, Zig 0.16.0 in `%LOCALAPPDATA%\Programs`, LLVM for bindgen, VS Build Tools). This host can't build it (no GUI dev packages here).

The fork adds settings.json `cursor_style`, `cursor_blink` and `cursor_thickness` (the terminal cursor's default, its blink, its thickness; `src/vt.rs`, `src/terminal.rs`, `defaults/AGENTS.md`), and a desired-state zoom: `pane.zoom {pane, on}` sets it (no `on` still toggles; with `on` a lone pane is "nothing to zoom") and `ls` gives each tab's `zoomed` (`src/window.rs` `zoom_pane` and `world()`, `src/commands.rs`, `defaults/AGENTS.md`, `src/SKILL.md`). It also keeps the focused pane's highlight border while a frameless popup holds the keyboard (a key catcher such as `~/herdr-app-mods`' `prefix`; `focused_path` in `src/window.rs`). Its editor highlighter names more scopes for `EditorState`'s `syntax` map: property (JSON, YAML and JS keys, CSS properties, members), tag, attribute, and markdown's heading, bold, italic, code and link, and diff's inserted and deleted, plus finer names that fall back to their root (keyword.control, variable.language, type.namespace and the rest `typings.rs` lists, which Python's grammar fills); quotes take their string's color and comment marks their comment's (`vendor/gpui-kit/crates/shell/src/syntax.rs`, `typings.rs`). Fork-only files: this one, `scripts/fork-install.ps1`, `.claude/skills/sync-upstream/`.

A build from source never updates itself or any core, so updates are by hand: take upstream's latest release tag by merge, never rebase and never `upstream/master`, via `/sync-upstream`. Host setup and the cores: `~/.local/share/herdr-app/README.md` on mycroftxxx.
