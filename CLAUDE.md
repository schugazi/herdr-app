# Personal fork of Herdr (the desktop app)

Fork `schugazi/herdr-app` of upstream `herdrdev/herdr-app`; read upstream's `AGENTS.md` for the code. Edited in `~/herdr-app` on mycroftxxx (branch `master`), built and installed on multivac from `C:\Users\nmsch\herdr-app` with `scripts/fork-install.ps1` (CI's toolchain: Rust 1.95.0, Zig 0.16.0 in `%LOCALAPPDATA%\Programs`, LLVM for bindgen, VS Build Tools). This host can't build it (no GUI dev packages here).

The fork adds settings.json `cursor_style`, `cursor_blink` and `cursor_thickness` (the terminal cursor's default, its blink, its thickness; `src/vt.rs`, `src/terminal.rs`, `defaults/AGENTS.md`), and a desired-state zoom: `pane.zoom {pane, on}` sets it (no `on` still toggles; with `on` a lone pane is "nothing to zoom") and `ls` gives each tab's `zoomed` (`src/window.rs` `zoom_pane` and `world()`, `src/commands.rs`, `defaults/AGENTS.md`, `src/SKILL.md`). It also keeps the focused pane's highlight border while a frameless popup holds the keyboard (a key catcher such as `~/herdr-app-mods`' `prefix`; `focused_path` in `src/window.rs`). Its editor highlighter names more scopes for `EditorState`'s `syntax` map: property (JSON, YAML and JS keys, CSS properties, members), tag, attribute, and markdown's heading, bold, italic, code and link, and diff's inserted and deleted, plus finer names that fall back to their root (keyword.control, variable.language, type.namespace and the rest `typings.rs` lists, which Python's grammar fills); quotes take their string's color and comment marks their comment's (`vendor/gpui-kit/crates/shell/src/syntax.rs`, `typings.rs`). Mods get `reloadImage(path)`, which drops one picture from GPUI's asset cache so a frame file rewritten under `data/` shows again (`src/mods.rs`, `Request::ReloadImage` in `src/window.rs`, `defaults/herdr.d.ts`; `~/herdr-app-mods`' `schu-browser` needs it). Mods also get `highlight(language, text)`, the editor's highlighter for code they draw themselves: each line's pieces with the `syntax` name that colors them, on a worker thread (`highlight_lines` in `syntax.rs`, `src/mods.rs`, `defaults/herdr.d.ts`; `~/herdr-app-mods`' `schu-changes` colors its diff with it). Each mod function the fork adds is also registered in the render tests' `herdr` fixture (`module` in `src/mods/render_tests.rs`), since a module must register every function `herdr.d.ts` declares. Overlay windows opened with `resizable: true` resize from their left, right and bottom edges and both bottom corners, and a keyed one remembers its size in `windows.json` `sizes` (`src/window/movable.rs`, `Overlay.resizable` in `src/window.rs`, `defaults/AGENTS.md`, `defaults/herdr.d.ts`; `~/herdr-app-mods`' Dispatch window uses it). When the tab area changes, only the shown space's hidden tabs are sized to it (`fit_hidden_tabs` in `src/window/pane_size.rs`): side panels remembered per space give each space its own area, so sizing every space's resized their programs on each switch. A terminal's size on screen reaches its program 100 ms after it first changes, and not at all if it changed back meanwhile (`Grid::settle` in `src/terminal.rs`; sizes before it attaches and with a new cell (font size, zoom) go out at once, a drag resizes every 100 ms, a pane shown again waits afresh), so a space switch's frame or two with the last space's side panels doesn't make Claude Code redraw twice. `.sql` files use its own T-SQL grammar (`crates/shell/src/tsql.sublime-syntax`, loaded through syntect's `yaml-load` feature) instead of syntect's default SQL, which reads `#temp` tables as comments. Fork-only files: this one, `scripts/fork-install.ps1`, `.claude/skills/sync-upstream/`.

A build from source never updates itself or any core, so updates are by hand via `/sync-upstream`: the app takes upstream's latest release tag by merge, never rebase and never `upstream/master`; every core goes to the latest stable core release the app is compatible with, assessed on its own each run. Host setup and the cores: `~/.local/share/herdr-app/README.md` on mycroftxxx.
